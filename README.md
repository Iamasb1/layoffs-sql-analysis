# Company Layoffs Data Analysis (SQL)

## Project Overview

This project focuses on cleaning, transforming, and analysing company layoffs data using SQL. The goal is to identify trends in layoffs across companies, industries, countries, and time periods.

## Tools Used

* MySQL

## Skills Demonstrated

* Data cleaning and preprocessing
* Duplicate identification and removal
* Handling missing values
* Data standardisation
* Date conversion and transformation
* Common Table Expressions (CTEs)
* Window functions
* Aggregate functions and exploratory data analysis
* Ranking companies by yearly layoffs

## Project Workflow

1. Created staging tables to preserve the original dataset.
2. Identified and removed duplicate records.
3. Standardised industry and country values.
4. Converted date values into a usable date format.
5. Handled missing and incomplete records.
6. Analysed layoffs by company, industry, country, company stage, and year.
7. Examined monthly layoff trends and rolling totals.
8. Ranked companies by layoffs for each year.

## Key Questions

* Which companies recorded the largest layoffs?
* Which industries were most affected?
* Which countries experienced the highest layoffs?
* How did layoffs change over time?
* Which companies had the highest layoffs in each year?
